# Meridian Fitness: Class Booking, Business Requirements (v1)

Owner: Sara Lind, Head of Member Experience.

## Scope of release 1

Release 1 is web booking only. A mobile app is planned for a later release.

## Requirements

R1. Members can book a class on the website and cancel it up to 2 hours before it starts.
R2. Members receive a reminder 24 hours before the class.
R3. Cancellations later than 2 hours before the class count as a no-show.
